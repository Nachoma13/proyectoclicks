# AI Desktop Agent

Proyecto de agente IA capaz de:

- controlar navegador,
- abrir aplicaciones,
- automatizar escritorio,
- usar Selenium,
- usar IA con OpenAI,
- automatizar YouTube.

## Stack

Frontend:
- React
- Vite
- Tailwind

Backend:
- Java 21
- Spring Boot
- Selenium
- LangChain4j
- OpenAI
